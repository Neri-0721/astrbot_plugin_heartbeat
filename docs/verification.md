# 验证范围

当前验证基线为 AstrBot 4.29.3。验证工具使用离线 Provider、测试会话和独立临时目录，无需在线模型凭据或真实聊天平台。

3.3.0 验证：Windows、Python 3.12、Ruff 0.15.12；111 项自动化测试通过，Ruff 检查与格式检查通过。3.2.0 的 85 项用例保留。真实框架离线检查使用独立临时目录，验证下述行为。

## 门控模式

- 静默轮只有一次门控调用，不选择或调用表达模型，不污染普通聊天历史。
- 联系轮一次门控、一次表达；近期交互不硬拦截，实际台词成功发送后才写入历史和联系记录。
- 显式免打扰、日联系预算在门控选择联系时仍阻止表达调用；表达模型也可拒绝发送。
- 校验结构化响应、重复 JSON key、笔记容量及整批变更；失败不回退或自动补调模型。
- 门控/表达期间新用户消息、人格变化、主动中断及上层取消不会发送过时结果，释放会话锁。
- 发送失败不计成功；逐阶段记录用量而不保存私密推理；日志写入失败在请求前阻止模型调用。
- 决策文件的会话隔离、原子替换、容量清理和路径校验。
- 新宿主结构化配置适配；媒体只保留占位，旧内部摘要不会作为真实对话输入。

真实框架检查另跑三轮门控场景：静默（门控1/表达0）、近期交互后联系（1/1）、显式免打扰（1/0）；共3次门控和1次表达的固定离线响应。使用宿主真实 Cron 事件、ProviderRequest、请求钩子和 MessageChain，发送到假平台；网络推理和真实消息均为0。

## 自动化行为测试

`python -m unittest discover -v` 覆盖：

- 45、90、120、1440 分钟的真实到期时间；会话公平性与 last 模式。
- 后台活动和联系限制分离；跨午夜、指定时区、日预算与暂停。
- 2/4/8/16 小时未回应退避、真实用户回复重置；同话题可延续，完全相同消息仍去重。
- 发送前出现新用户消息、发送失败、并发工具调用和跨会话发送阻止。
- 全部会话/预算/时间恢复，旧文件迁移，原子保存和损坏文件保护。
- 手册优先级、真正的会话覆盖、旧副本继承和显式文件缺失。
- 完整执行周期持锁、请求前钩子顺序、无模型和准备阶段跳过不计费、前台让行。
- 普通聊天不解除全局暂停，配置重载更新全部参数，后台请求不冒充用户消息。
- 配置名单默认关闭，普通聊天不自动开启，旧状态和旧单会话文件不授予许可。
- 开启/关闭命令保存同一份配置；重启恢复、保存失败、后台事件拒绝、群聊管理员权限。
- 多会话独立开关和轮次记录，未开启会话不影响 last 目标；缺少信息的旧会话不挡住其他会话。
- 宿主会话/LLM/插件禁用时不构建 Agent、不消耗模型调用；准备中关闭和发送前撤销许可。
- 默认允许凌晨及深夜活动、近期互动窗口缩短；联系预算与后台预算独立。
- 2.5/3.1 默认手册的字节级备份及幂等迁移、BOM/CRLF、旧继承副本、自定义修改保护与原子替换失败保护。

其中框架适配单测使用可控替身，适合 CI；它们与下面的真实框架检查分开。

## 真实框架、离线 Provider

`tools/verify_astrbot.py --source <AstrBot源码目录>` 在独立子进程及临时 `ASTRBOT_ROOT` 中执行，宿主数据库和配置不参与。使用真实 `build_main_agent`、Runner、工具执行器、消息事件、工具类型和装饰器，以及固定响应的离线 Provider。

完整 Agent 路径检查三轮：免打扰期间仍完成事情但阻止发送；解除显式免打扰后发送到假平台；模拟用户回应且联系间隔已经过后，同一话题可发送不同内容。检查所选人格、请求前记忆标记、Agent 开始/结束及工具事件，保存内部摘要。三轮总共使用六次离线 Provider 响应、两次假平台送达；另有门控路径的一次假平台送达。无网络请求或真实消息。还检查插件导入、命令和工具注册、初始化与停用。

在临时数据库中分别关闭宿主会话、LLM 和 heartbeat 插件，验证三种情况均不调用离线 Provider；加入一个有真实插件归属的测试工具，验证会话禁用规则使其不进入模型工具列表。使用真实 `AstrBotConfig` 写入并重新读取临时配置，验证命令开启/关闭与配置名单一致；普通聊天不自动登记未开启的会话。

## 静态与打包

通过 `ruff check .`、`ruff format --check .`；配置 JSON 与元数据解析一致。发布包排除 `.git`、缓存、开发验证产物和用户数据，并检查大小。

## 尚需真实交互验证

- 具体人格/记忆插件对后台事件的解释，以及实际模型是否会恰当决定静默、分享或跟进。
- 实际聊天平台的送达与媒体能力、第三方工具的行为。
- 后续 AstrBot 版本的接口兼容性；版本范围声明不等于已逐一验证所有版本。

发送控制覆盖本插件包装的消息工具及事件发送入口。第三方工具可拥有独立外部通信能力，这些测试不证明宿主环境被隔离。
